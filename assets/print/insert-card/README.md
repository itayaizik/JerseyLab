# כרטיס אריזה A5 — JerseyLab

כרטיס דו-צדדי שנכנס לאריזה עם החולצה. צד א' קבלת פנים + QR לקטלוג,
צד ב' שש הוראות טיפול.

## קבצים

- `card.html` — העיצוב. זה המקור, כאן עורכים.
- `jerseylab-insert-a5.pdf` — הקובץ להדפסה. נוצר מ-`card.html`.
- `build.sh` — מייצר את ה-PDF מחדש.
- `../fonts/` — Heebo ו-Space Mono כקבצים מקומיים, כדי שההדפסה
  לא תלויה באינטרנט ותיראה זהה בכל מחשב.

## מידות

148×210mm (A5) לאחר חיתוך, עם 3mm bleed מכל צד — קובץ של 154×216mm.
הטקסט נשאר 8mm מקו החיתוך, כך ששום דבר לא נחתך בבית הדפוס.

## עריכה

פותחים את `card.html` בדפדפן, משנים טקסט, מריצים `./build.sh`.
הצבעים והפונטים הם אותם טוקנים של האתר (`tailwind.config.js`,
`src/index.css`) — אם הפלטה של החנות משתנה, לעדכן גם כאן.
